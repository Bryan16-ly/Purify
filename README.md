Purify

A lightweight Android app for managing installed applications and system packages.

Purify membantu pengguna mengelola aplikasi Android, termasuk aplikasi sistem, melalui antarmuka yang sederhana dan praktis.

Features

- App Management — Melihat dan mengelola aplikasi yang terpasang.
- System App Management — Mengelola paket aplikasi sistem Android.
- Disable & Uninstall — Menonaktifkan atau menghapus paket sesuai dukungan sistem dan akses yang tersedia.
- Access Integration — Mendukung metode akses yang tersedia di aplikasi, seperti ADB atau Root, sesuai implementasinya.
- Application Status — Melihat aplikasi berdasarkan statusnya, termasuk aplikasi nonaktif atau terhapus jika didukung.

Requirements

- Android device.
- Metode akses yang diperlukan untuk operasi tertentu, bergantung pada fitur yang digunakan.
- ADB atau Root hanya diperlukan jika operasi yang dipilih membutuhkannya.
